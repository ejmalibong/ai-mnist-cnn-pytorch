# MNIST CNN Classifer with PyTorch

## Overview

This is an implementation of CNN classifier for MNIST dataset with pytorch.

## Setup and Run

### 1. Clone Git repo

```bash
git clone https://github.com/coderanger428/ai-mnist-cnn-pytorch.git
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run

```bash
python src/train.py
# OR
jupyter notebook experiment.ipynb
```
